# 🃏 ScratchCards  

Интерактивная **карточка-«стирашка»** на Vue + Pixi.js.

🔗 **Демо**: [https://nigilen.github.io/kolino__scratch-cards/](https://nigilen.github.io/kolino__scratch-cards/)

---

### 💡 Особенности

- **Два слоя через Pixi.js** — реализация маскирования с помощью `RenderTexture` и `Graphics` для плавного «стирания».  
- **Гибкая структура контента** — под стираемым слоем можно размещать как изображения, так и текст (например, призы или надписи типа «Empty»).  
- **Адаптивный рендеринг** — корректное отображение на любых экранах благодаря логическому размеру сцены и автоматическому масштабированию.  
- **Чистая архитектура** — данные о призах вынесены отдельно, логика стирания инкапсулирована, компонент легко переиспользовать. 

---

### 🛠 Технологии

- **Vue 3** (Composition API)  
- **Pixi.js** 
- **HTML5 / CSS3 / JavaScript / TypeScript**
- **Figma** — дизайн макета и графических элементов

---

### ▶ Как запустить локально

1. Устанавливаем зависимости:
```bash
npm install
```

2. Запускаем dev-сервер:
```bash
npm run dev
```
---

> Проект создан как пример аккуратной реализации игровой механики «раскрой приз», сочетающей декларативный Vue и мощь WebGL через Pixi.js — даже в простых задачах можно соблюдать frontend-дисциплину и не «срезать углы».
